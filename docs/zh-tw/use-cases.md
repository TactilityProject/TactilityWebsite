Tactility 把便宜的 ESP32 裝置變成一台口袋電腦，可以依手邊的任務自由打造。以下是一些常見的用法。

## 專業人員 {#professionals}

對技術人員、電工、安裝工程師和保全從業人員來說，Tactility 裝置是一個口袋大小的工具箱，能帶到筆電不方便去的地方。

- **現場工具**：在現場診斷和設定裝置。例如，**Serial Console** App 透過 UART 與裝置通訊，**GPIO** App 即時顯示每個腳位的狀態。
- **量測與感測器**：透過 I2C、SPI 和 UART 讀取感測器和模組的資料，在支援的裝置上還能使用 GPS、音訊等功能。
- **無線**：使用 Wi-Fi、低功耗藍牙、ESP-NOW 和 LoRa Mesh 網路，即使在沒有網路訊號的地方也能運作。
- **可擴充**：在執行期間新增周邊裝置和驅動程式，不需要重新燒錄韌體。
- **客製化工具**：從 SD 卡執行你自己的 App 和指令碼，開機直接進入你需要的工具。
- **現代化工具鏈**：在瀏覽器中遠端管理裝置，透過 Wi-Fi 開發和部署 App，並在電腦上用模擬器測試。

## 遊戲 {#gaming}

ESP32 裝置的效能比外表看起來強得多。Tactility 讓遊戲完全掌控螢幕和輸入，並能快速存取顯示驅動程式。

- **遊戲**：用 [Jet](https://github.com/cubecoders/jet) 引擎玩 3D 遊戲，或執行用 Deki 開發的遊戲。
- **流暢執行**：DOOM 執行流暢，同時 Wi-Fi 在背景保持連線。Mesh 訊息照常接收，遊戲結束後就能查看。
- **隨心操作**：使用觸控螢幕、鍵盤、軌跡球或按鍵。

## 創客 {#makers}

獻給喜歡玩硬體、製作自己的裝置，或把想法變成專案的人。

- **從手邊的硬體開始**：Tactility 可以在[眾多裝置](zh-tw/supported-devices.md)上執行，從附鍵盤的掌上型裝置到平板和價格實惠的「Cheap Yellow Display」（CYD）開發板。
- **打造你自己的裝置**：裝置透過裝置樹（device tree）描述，所以為自己的硬體新增支援，主要就是描述硬體並補上缺少的驅動程式。
- **不需要重新編譯韌體就能開發 App**：把 App 放到 SD 卡上，或從電腦透過 Wi-Fi 安裝。用 [LVGL](https://lvgl.io) 打造使用者介面，或直接在螢幕上繪製像素。
- **在電腦上實驗**：模擬器可在 Linux、macOS 和 Windows（WSL）上執行，並提供不同螢幕尺寸的設定。
- **直接在裝置上寫程式**：在 Terminal 中使用 **xcc700** 和 **rcc700** 編譯器，直接在裝置上編譯小型 C 程式。
- **連接一切**：I2C、SPI 和 UART 用起來更簡單、更安全，驅動程式為螢幕、觸控、鍵盤、GPS、音訊和電源提供統一的介面。
- **不只是 App**：App 套件可以包含開機後即可使用的驅動程式模組和背景服務。
- **玩音樂**：把裝置變成任何 DAW 或合成器的 MIDI 控制器，或直接在裝置上創作晶片音樂（chiptune）。
- **了解作業系統的原理**：Tactility 是開放原始碼的，核心、驅動程式模型和服務都可以深入研究。

請參閱[開發者文件](https://docs.tactilityproject.org)（英文）開始開發，也歡迎在[社群](zh-tw/community.md)分享你的作品。
