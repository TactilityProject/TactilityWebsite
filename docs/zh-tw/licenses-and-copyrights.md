## Tactility {#tactility}

Tactility 包含許多子專案，每個專案都有各自的授權。

關於 Tactility 作業系統和 Tactility SDK，請參閱：
- [GitHub 上的授權詳細資訊](https://github.com/TactilityProject/Tactility/blob/main/LICENSE.md)
- [GitHub 上的第三方聲明](https://github.com/TactilityProject/Tactility/blob/main/THIRD-PARTY-NOTICES.md)

使用 Tactility SDK 開發的 App 可以採用專有授權，因此你可以開發閉源和商業 App。屬於 Tactility 韌體一部分的 App 不能以專有授權發布。

> [!NOTE]
> 本譯文僅供參考，具有法律效力的是 GitHub 上的授權條款原文。
