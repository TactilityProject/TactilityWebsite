Any ESP32 device should be able to run Tactility, because drivers can be implemented for any hardware.
Some hardware combinations are officially supported.

<!-- devices -->

## Legend

- **⭐**: recommended by the developer.
- **External RAM**: the device has external RAM (PSRAM). Devices without it can run Tactility, but memory is tight.
- **SD card**: the SD card slot works. "No SD card" means it is unavailable, broken or not implemented.
- **Community tested**: these boards are not owned by the developer, so quality control is limited to community efforts.
- **Incubating**: support is still being worked on.

### Feature status

Device pages use the following status markers:

- ✅ Supported
- ⚠️ Partially supported or buggy
- 🚧 Hardware is capable, but not yet implemented
- ❌ Not supported
