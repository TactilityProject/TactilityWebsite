A CYD ("Cheap Yellow Display") board.

> [!WARNING]
> The device does not power on with a USB-C to USB-C cable. Use a USB-C to USB-A cable instead.

## Feature support

| Feature | Status | Notes |
|-|-|-|
| SD card | ✅ | |
| External I2C | ✅ | P4 JST SH 1.0 header: GPIO-17 (SDA), GPIO-18 (SCL) |
| External UART | ✅ | P4 JST SH 1.0 header: GPIO-17 (RX), GPIO-18 (TX) |
| Bluetooth | ✅ | BLE |
| Touch | ✅ | `GT911` |
| Backlight control | ✅ | Brightness control |
| USB Mass Storage | ❌ | The USB port is wired to a `CH340C` USB-serial chip instead of the native ESP32-S3 USB pins |

## Known issues

- Touch: out of the box, the touch panel resolution does not match the screen resolution. This can be fixed by flashing settings to the touch driver, but Tactility doesn't include such a fix yet.
