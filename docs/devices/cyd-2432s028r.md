A CYD ("Cheap Yellow Display") board.

## Hardware revisions

The three revisions of this board differ in the display. Everything else (pins, touch, SD card, RGB LED) is the same.

| Revision | Display controller | Install |
|-|-|-|
| v1 | `ILI9341` | [Install](https://install.tactilityproject.org/#cyd-2432s028r) |
| v2 | `ILI9341`, different panel | [Install](https://install.tactilityproject.org/#cyd-2432s028rv2) |
| v3 | `ST7789` | [Install](https://install.tactilityproject.org/#cyd-2432s028rv3) |

Each firmware contains the display driver for one revision only, so it has to match your board.
The revisions look alike. If the screen stays blank or the colours look wrong after installing, you probably have another revision: install one of the other firmwares.

## Feature support

The same features are supported on all three revisions.

| Feature | Status | Notes |
|-|-|-|
| SD card | ✅ | |
| Touch | ✅ | Resistive, `XPT2046` |
| Backlight control | ✅ | Brightness control |
| Bluetooth | ❌ | Not available in the current firmware |
