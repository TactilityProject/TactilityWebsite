A CYD ("Cheap Yellow Display") board.

> [!WARNING]
> Version 2 of this board is not supported. Only install Tactility on version 1 or version 3, and pick the firmware that matches your board.

## Hardware variants

- v1: supported. Install the v1 firmware.
- v2: not supported. There is no Tactility firmware for this version, and the v1 and v3 firmware are not made for it.
- v3: supported. Install the v3 firmware.

## Feature support

The same features are supported on v1 and v3.

| Feature | Status | Notes |
|-|-|-|
| SD card | ✅ | |
| Touch | ✅ | Resistive, `XPT2046` |
| Backlight control | ✅ | Brightness control |
| Bluetooth | ❌ | Not available in the current firmware |
