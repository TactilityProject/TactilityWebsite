## Hardware variants

Both the original Cardputer and the Cardputer v1.1 are supported.

## Feature support

| Feature | Status | Notes |
|-|-|-|
| SD card | ✅ | |
| Keyboard | ✅ | |
| Power status | ✅ | |
| Speaker | ✅ | `NS4168` |
| Microphone | ✅ | `SPM1423` |
| Grove port | ✅ | |
| USB Mass Storage | ✅ | |
| Bluetooth | ✅ | BLE |
| Backlight control | ✅ | Brightness control |
| Touch | ❌ | No touchscreen |

## Usage notes

Navigate with the up, down and enter buttons. Hold `Fn` to use the up and down arrow keys.
