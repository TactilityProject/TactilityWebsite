# CL-32

The following hardware revisions are supported:

- v0.2
- v0.3
- v0.4 with reflective LCD

## Features

- ✅ SD card
- ✅ Keyboard
- ✅ Stemma/Qwiic port
- ✅ Grove port (pin 47/48 configurable as I2C or UART)
- ✅ Power status and power control (v0.4)
