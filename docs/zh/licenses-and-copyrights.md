## Tactility {#tactility}

Tactility 包含许多子项目，每个项目都有各自的许可。

关于 Tactility 操作系统和 Tactility SDK，请参阅：
- [GitHub 上的许可详情](https://github.com/TactilityProject/Tactility/blob/main/LICENSE.md)
- [GitHub 上的第三方声明](https://github.com/TactilityProject/Tactility/blob/main/THIRD-PARTY-NOTICES.md)

使用 Tactility SDK 开发的应用可以采用专有许可，因此你可以开发闭源和商业应用。属于 Tactility 固件一部分的应用不能以专有许可发布。

> [!NOTE]
> 本译文仅供参考，具有法律效力的是 GitHub 上的许可文本。
