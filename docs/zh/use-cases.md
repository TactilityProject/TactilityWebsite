Tactility 把廉价的 ESP32 设备变成一台口袋电脑，可以根据手头的任务自由定制。下面是一些常见的用法。

## 专业人员 {#professionals}

对于技术人员、电工、安装工程师和安防从业者来说，Tactility 设备是一个口袋大小的工具箱，可以去笔记本电脑不方便去的地方。

- **现场工具**：在现场诊断和配置设备。例如，**Serial Console** 应用通过 UART 与设备通信，**GPIO** 应用实时显示每个引脚的状态。
- **测量与传感器**：通过 I2C、SPI 和 UART 读取传感器和模块数据，在支持的设备上还能使用 GPS、音频等功能。
- **无线**：使用 Wi-Fi、低功耗蓝牙、ESP-NOW 和 LoRa Mesh 网络，即使在没有网络覆盖的地方也能工作。
- **可扩展**：在运行时添加新的外设和驱动，无需重新烧录固件。
- **定制工具**：从 SD 卡运行你自己的应用和脚本，开机直接进入你需要的工具。
- **现代化工具链**：在浏览器中远程管理设备，通过 Wi-Fi 开发和部署应用，并在电脑上用模拟器测试。

## 游戏 {#gaming}

ESP32 设备的性能比看上去强得多。Tactility 让游戏完全掌控屏幕和输入，并能快速访问显示驱动。

- **游戏**：用 [Jet](https://github.com/cubecoders/jet) 引擎玩 3D 游戏，或运行用 Deki 开发的游戏。
- **流畅运行**：DOOM 运行流畅，同时 Wi-Fi 在后台保持连接。Mesh 消息照常接收，游戏结束后就能查看。
- **随心操作**：使用触摸屏、键盘、轨迹球或按键。

## 创客 {#makers}

献给喜欢折腾硬件、制作自己的设备或把想法变成项目的人。

- **从手头的硬件开始**：Tactility 可以运行在[众多设备](zh/supported-devices.md)上，从带键盘的掌机到平板和价格实惠的“Cheap Yellow Display”（CYD）开发板。
- **打造你自己的设备**：设备通过设备树描述，所以为自己的硬件添加支持，主要就是描述硬件并补上缺少的驱动。
- **无需重新编译固件即可开发应用**：把应用放到 SD 卡上，或从电脑通过 Wi-Fi 安装。用 [LVGL](https://lvgl.io) 构建用户界面，或直接在屏幕上绘制像素。
- **在电脑上实验**：模拟器可在 Linux、macOS 和 Windows（WSL）上运行，并提供不同屏幕尺寸的配置。
- **直接在设备上写代码**：在 Terminal 中使用 **xcc700** 和 **rcc700** 编译器，直接在设备上编译小型 C 程序。
- **连接一切**：I2C、SPI 和 UART 使用起来更简单、更安全，驱动为显示屏、触摸、键盘、GPS、音频和电源提供统一接口。
- **不止于应用**：应用包可以包含开机后即可使用的驱动模块和后台服务。
- **玩音乐**：把设备变成任何 DAW 或合成器的 MIDI 控制器，或者直接在设备上创作芯片音乐。
- **学习操作系统的原理**：Tactility 是开源的，内核、驱动模型和服务都可以深入研究。
