## Tactility {#tactility}

Tactility tiene muchos subproyectos, y cada proyecto tiene su propia licencia.

Para el sistema operativo Tactility y el SDK de Tactility, consulta:
- [Detalles de la licencia en GitHub](https://github.com/TactilityProject/Tactility/blob/main/LICENSE.md)
- [Avisos de terceros en GitHub](https://github.com/TactilityProject/Tactility/blob/main/THIRD-PARTY-NOTICES.md)

Las apps creadas con el SDK de Tactility pueden tener una licencia propietaria, así que puedes crear apps de código cerrado y con fines comerciales.
Las apps que forman parte del firmware de Tactility no pueden publicarse con una licencia propietaria.

> [!NOTE]
> Esta traducción es solo informativa. Los textos de licencia en GitHub son los que tienen validez legal.
